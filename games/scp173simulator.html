About the game

A role-reversal horror game built for GMTK Game Jam 2023. The player controls SCP-173 inside a containment facility.

This game contains animations of humans dying, but no visible blood.

Controls

Keyboard and mouse.

Install instructions

Download the ZIP file, extract it, and run SCP 173 Simulator.exe.
